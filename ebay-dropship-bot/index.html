Comment utiliser cet outil

  1. Audit d'annonce — collez votre titre, description et infos logistiques avant de publier : vous obtenez un score et une liste concrète de corrections (bloquantes / à améliorer).
  2. Générateur — renseignez les infos produit, obtenez 3 titres optimisés (≤80 caractères) et une description HTML pro prête à copier-coller dans eBay.
  3. Sourcing & Marge — calculez votre marge nette réelle après frais eBay et évaluez la viabilité d'une niche produit avant de vous lancer.
  4. Base de connaissances — politique dropshipping eBay, règles AliExpress/Amazon, GPSR, VeRO, TVA/IOSS, indicateurs de performance.
