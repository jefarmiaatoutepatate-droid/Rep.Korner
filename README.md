# LUXE BRAND — Boutique e-commerce premium

## 🎯 Présentation

**LUXE BRAND** est une boutique e-commerce premium spécialisée dans la revente de vêtements, chaussures et accessoires authentiques des plus grandes marques (Nike, Adidas, New Balance, Birkenstock, Carhartt, Converse, etc.).

Design minimaliste noir/blanc/or, animations fluides, 100% responsive.

---

## ✅ Pages créées

| Page | Fichier | Contenu |
|------|---------|---------|
| Accueil | `index.html` | Hero slider, stats, catégories, grilles produits, marques, avis, newsletter, footer |
| Boutique | `boutique.html` | Catalogue, filtres avancés, tri, recherche, pagination |
| Fiche Produit | `produit.html` | Galerie zoom, tailles/couleurs, panier, wishlist, onglets, produits similaires |
| Marques | `marques.html` | Fiches détaillées Nike/Adidas/NB/Birkenstock/Carhartt, grille compacte |
| À Propos | `a-propos.html` | Histoire, timeline, valeurs, équipe |
| Contact | `contact.html` | Formulaire validé, canaux, FAQ accordéon |
| Admin | `admin.html` | Dashboard KPIs, graphiques Chart.js, commandes, stocks, clients, promos |

## 📁 Structure

```
index.html / boutique.html / produit.html / marques.html / a-propos.html / contact.html / admin.html
css/style.css          ← Styles complets
js/data.js             ← Catalogue 16 produits + 6 marques
js/store.js            ← Panier & Wishlist (localStorage)
js/main.js             ← Navigation, animations, hero slider, etc.
```

## 🔗 URIs principales

| URL | Description |
|-----|-------------|
| `/index.html` | Accueil |
| `/boutique.html?category=sneakers` | Filtrer par catégorie |
| `/boutique.html?brand=Nike` | Filtrer par marque |
| `/boutique.html?filter=sale` | Soldes |
| `/boutique.html?search=air+max` | Recherche |
| `/produit.html?id=nike-air-max-90-001` | Fiche produit |
| `/marques.html#nike` | Ancre marque |
| `/admin.html` | Dashboard admin |
