Méthode 1 — Mettre en ligne (recommandé)

La solution la plus simple : l'onglet Publish de Genspark

Votre site est déjà hébergé ici. Il suffit de cliquer sur Publish dans l'interface Genspark pour obtenir une URL publique partageable en quelques secondes — sans aucune configuration.

1

Ouvrir l'onglet "Publish"

Dans l'interface Genspark, cliquez sur l'onglet Publish en haut à droite de l'éditeur.

2

Cliquer sur "Publish"

Un bouton bleu vous permet de publier instantanément. Genspark génère une URL du type https://xxxx.genspark.site.

3

Partager le lien

Copiez l'URL et partagez-la avec vos clients, amis ou investisseurs. Le site est accessible 24/7.

Méthode 2 — Télécharger via Git

Les fichiers sont versionnés dans un dépôt Git. Utilisez la commande git clone pour récupérer tout le projet en local.

# Ouvrir un terminal (CMD, PowerShell, Terminal Mac/Linux)

# Se placer dans le dossier souhaité
cd ~/Documents

# Cloner le dépôt (remplacer par l'URL réelle du projet)
git clone [URL_DU_REPO_GENSPARK] tkr-corp

# Entrer dans le dossier
cd tkr-corp

# Ouvrir avec VS Code
code .

Où trouver l'URL Git ?

Dans l'interface Genspark, cherchez l'icône Git ou le bouton "Clone". L'URL ressemble à https://git.genspark.ai/project/xxxxx

1

Télécharger GitHub Desktop

Rendez-vous sur desktop.github.com et installez l'application (Windows / Mac).

2

File → Clone repository

Cliquez sur File > Clone repository > URL et collez l'URL du repo Genspark.

3

Choisir un dossier local

Sélectionnez l'emplacement sur votre disque et cliquez sur Clone.

1

Ouvrir VS Code

Installez VS Code depuis code.visualstudio.com si ce n'est pas déjà fait.

2

Ctrl+Shift+P → "Git: Clone"

Ouvrez la palette de commandes et tapez Git: Clone, puis collez l'URL du repo.

3

Ouvrir avec Live Server

Installez l'extension Live Server, faites clic droit sur index.html → Open with Live Server.

Méthode 3 — Héberger sur un serveur externe

GitHub Pages

Gratuit, fiable, HTTPS automatique

Push vos fichiers sur un dépôt GitHub public → Settings → Pages → choisir la branche main → URL https://username.github.io/tkr-corp

Netlify

Drag & Drop, CDN mondial

Rendez-vous sur netlify.com → "Add new site" → faites glisser votre dossier de projet → URL en ligne en 30 secondes.

Vercel

Ultra-rapide, domaine personnalisé

Connectez votre repo GitHub à vercel.com → déploiement automatique à chaque push. Domaine gratuit inclus.

Hébergement FTP classique

OVH, Ionos, O2Switch…

Copiez tous les fichiers dans le dossier public_html/ via FileZilla (FTP). Achetez un domaine (.fr, .com) pour ~10€/an.

⚡ Netlify Drop — Le plus rapide (sans compte requis !)

  • Allez sur app.netlify.com/drop
  • Glissez-déposez le dossier entier du projet
  • Obtenez une URL live en moins de 1 minute
  • Ajoutez un domaine personnalisé plus tard si besoin

Questions fréquentes

Peut-on faire du ZIP / téléchargement direct ?

L'environnement Genspark est un éditeur en ligne — il ne génère pas de fichiers ZIP. La méthode recommandée est git clone (récupère tous les fichiers en une commande) ou Publish pour mettre en ligne directement.

Le site fonctionne-t-il en local (sans serveur) ?

Oui ! Ouvrez directement index.html dans votre navigateur. Certaines fonctionnalités (localStorage, animations) fonctionnent parfaitement. Pour un rendu optimal, utilisez Live Server dans VS Code.

Comment ajouter de vrais paiements ?

Intégrez Stripe Checkout (stripe.com) ou PayPal SDK côté client. Les deux proposent des solutions 100% frontend pour les paiements sécurisés.

Comment accéder au dashboard admin ?

Naviguez vers /admin.html. Le dashboard affiche les KPIs, graphiques Chart.js et la gestion des commandes/produits. Pour une vraie authentification, connectez un backend ou utilisez Firebase.
